## 变更中发现并修复的次生问题

1. Clipboard API 可能永不结束，导致安装按钮无反馈；已加 800 ms 上界、本地 fallback 和中英文失败态。
2. 编辑器未打开 Timeline 时 resize 会读取空 projection；已加空状态短路并纳入静态回归。
3. 设计系统实现变更触发样式帧 digest 失效；已重新生成批准帧和 manifest，重新绑定 edit plan。
4. 仅使用字体目录 mtime 可能遗漏原地替换；缓存键已纳入文件名、大小、mtime 和 ctime，且最多保留 8 个键。

## 证据分层与结余风险

- 已证明：源码/静态、单元/集成、全量回归、本地真实浏览器、Pages 本地打包、本地安装器与主机特定性能。
- 提交后才能证明：远程 `main` 回读、官方 pipe 安装、macOS runner、Pages 公网和双 Agent 精确同步。
- 本轮无法自证：独立最终审查、真实创作者成片质量、激活/留存/效率/商业结果。
- 已知精确例外：`vinext@0.0.50 -> image-size@2.0.2` 的开发依赖告警；生产依赖告警为 0，修复需单独的 semver-major beta 兼容迭代。

结论仅是制作者复审，不代替独立终审。

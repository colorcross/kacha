# AI实践｜大灰AI

生产包 `dahui-ai`，show `ai-practice`；当前主依据为调用项目资料索引指向的有效方案。[完整剪辑方法](../../../docs/DAHUI_AI_EDITING_SYSTEM_V1.md)。

真实任务→输入条件→关键操作→结果检查→总成本→可复用资料。

- 叙事顺序：problem → inputs → workflow → result → quality-cost → reuse。
- 主片建议：5–10分钟。读书母片必须完整30–60分钟，切片不替代母片。
- 必备材料：task-input、tool-session、raw-output、quality-check、cost-log、reusable-artifact。
- 剪辑语法：`screen_steps`；声音：`dialogue_first`。
- 先整理证据和结构，再定字幕、插镜、图表与必要增强；真实来源不足时记录缺口，不生成伪证据。
- 交付节目合同、Timeline IR 映射、正常速度审片记录与成片；模板存在不等于验证通过。

- V6.3开场：第一句真人口播为一个完整问句，后接本期价值；结尾回答同一问题，保留条件。实际结果可同时入画。
- 每期用AI解决一个实际问题：工作、AI使用、Vibe Coding、学习、创作与生活均可；一个主交付物和预设验收，保留过程、结果、人工检查与总成本。

### 素材与剪辑交接（V1.2）

真实输入、操作与结果必须来自本期实测；图库只能解释抽象环境，不能代替操作成功。

按[网络素材工作流](../../network-materials.md)绑定当前段落、搜索、下载、看图/选段、许可和实际插镜；节目 `editingBrief` 保留首句问句、结尾回答与不可删条件。示意/署名要在实际交付落实，旧终审不随新时间线复用。

# 产品实践｜大灰AI

生产包 `dahui-ai`，show `product-practice`；当前主依据为调用项目V6.1。[完整剪辑方法](../../../docs/DAHUI_AI_EDITING_SYSTEM_V1.md)。

自己的需求、取舍、制作、迭代、真实使用与效果；区分原型、交付和市场结果。

- 叙事顺序：need → decision → build → iteration → use → next。
- 主片建议：5–10分钟。读书母片必须完整30–60分钟，切片不替代母片。
- 必备材料：product-version、development-record、usage-evidence、ai-role。
- 剪辑语法：`product_change`；声音：`dialogue_first`。
- 先整理证据和结构，再定字幕、插镜、图表与必要增强；真实来源不足时记录缺口，不生成伪证据。
- 交付节目合同、Timeline IR 映射、正常速度审片记录与成片；模板存在不等于验证通过。

# AI访谈解读｜大灰AI

生产包 `dahui-ai`，show `ai-interview`；当前主依据为调用项目资料索引指向的有效方案。[完整剪辑方法](../../../docs/DAHUI_AI_EDITING_SYSTEM_V1.md)。

原问题与上下文→嘉宾论证→事实核验→大灰判断；区别事实、嘉宾观点、预测和我的推断。

- 叙事顺序：question → context → argument → evidence → my-view → action。
- 主片建议：8–20分钟。读书母片必须完整30–60分钟，切片不替代母片。
- 必备材料：original-interview、source-timecodes、fact-check。
- 剪辑语法：`attributed_extract`；声音：`quiet_during_quotes`。
- 先整理证据和结构，再定字幕、插镜、图表与必要增强；真实来源不足时记录缺口，不生成伪证据。
- 交付节目合同、Timeline IR 映射、正常速度审片记录与成片；模板存在不等于验证通过。

- V6.3开场：第一句真人口播为一个完整问句，后接本期价值；结尾回答同一问题，保留条件。实际结果可同时入画。

### 素材与剪辑交接（V1.2）

原访谈片段保留原问题、上下文、日期和时间码；人物图库画面不能暗示其说过旁白中的话。

按[网络素材工作流](../../network-materials.md)绑定当前段落、搜索、下载、看图/选段、许可和实际插镜；节目 `editingBrief` 保留首句问句、结尾回答与不可删条件。示意/署名要在实际交付落实，旧终审不随新时间线复用。

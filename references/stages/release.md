# Release 阶段紧凑合同

目标：证明当前输出可发布，而不是证明命令跑完。

- 技术 QC 检查完整解码、几何、平均/声明 FPS、时长、A/V 漂移、黑帧、冻帧、
  静音、响度、真峰值、BGM 覆盖、stem 相对电平、组件混音重建和最终成片
  mix 匹配。
- 当前版本必须正常速度完整通看，并完成内容、连接、字幕准确/排版、画面连续、
  素材语义/授权、蒙版/美颜/PIP、设备试听、封面品牌、开头结尾十一项人工证据。
- 报告、视频、字幕、封面和 stem 的 hash 必须属于当前候选；旧报告不能继承。
- `run-metrics.json` 必须存在，记录各阶段耗时、Token、缓存命中和视频编码次数。
- 预览、自动 QC、编辑器状态和“渲染成功”都不是发布完成。
- 只有 `gate-release` 通过才到 `local_release_ready`；外传、上传和发布仍需用户
  明确授权。

# Edit 阶段紧凑合同

目标：用可解释规则生成紧凑但有呼吸的剪辑计划。

- 切镜只能因为信息、情绪或视角发生变化；同主体相邻镜头不得同景别，远/中/近/
  特写按叙事需要交替。
- 连接点先检查语义完整、动作连续、眼神/构图、音频 PTS 和前后 handle，再选择
  硬切、动作匹配、声音桥或短转场。转场不能掩盖错误切点。
- 呼吸感来自有意停稳、景别变化、克制推拉、视线方向和节奏密度变化；全程持续
  缩放或每句都加动效都不合格。
- 效果必须对应叙事触发；规则检索只给 1–3 个候选，弱模型选择配方参数，不自由
  发明执行命令。
- 置信度不足、规则冲突、身份/物理连续性风险时，只渲染局部预览并升级，不降低
  质量合同。
- 相同输入、配置、实现和 seed 必须生成相同计划 digest。

完成条件：EDL、连接审计、确定性 decision plan、局部预览范围和升级项全部明确。

# 字幕、封面、品牌与系列层

## 字幕依据与校准

最终时间线音频决定时间、实际说法、停顿和语气。原始文稿只用于校准专名、数字、术语、标点、吞音和上下文，不能静默覆盖真实发音。

流程：

1. 从最终音频重新转写；
2. 对照原稿和项目词表提出候选修正；
3. 复听数字、年份、单位、书名、人名、否定、条件、因果和结论；
4. 不确定项标记时间码并人工确认；
5. 保存重要修正的 `subtitleCorrectionLog`；
6. 正常速度通看最终烧录结果。

不能只把字幕改“正确”而让声音保留事实性口误。此时应重剪、补录、画面更正或忠实保留。

## 单行短视频字幕

9:16 口播默认：

- 每种语言单行；
- 不自动折行，不写强制换行；
- 无背景色、无底板；
- 超宽时按语义拆成连续字幕卡；
- 字幕位置主动上移，1080×1920 可从画面高度约 68%–72% 开始校准；
- 真实字体测宽，文字和阴影都不能越过安全边；
- 动词与宾语、数字与单位、否定结构、书名、固定搭配和比较项不能拆坏。

中文单卡可从约 8–14 个汉字开始，但字数不是验收标准。最终以真实渲染宽度、语义和阅读时间为准。

## 创作者字幕 profile

仅在项目显式启用相应创作者 profile 时使用。字体必须来自项目配置，不把作者机器上安装的商业字体当成公共默认值：

- 使用项目指定且授权可用的字体；
- 未指定时优先系统自带、许可明确的常规字重字体；
- 中文 fallback 可从 `Songti SC Regular`、`Kaiti SC Regular`、`STSong Regular` 中选择并实际渲染确认；
- `fontWeight=400`，不加粗、不描边；
- 无底板；
- 黑色柔和阴影默认 60% 不透明度；
- 用户要求增强时可到约 68%–75%，同时增加少量模糊和纵向偏移，不能变成硬描边。

字幕 profile 可以被项目元数据覆盖，不能被 Skill 强制应用到其他品牌。

## 双语字幕

用户明确需要时才启用。英文在上、中文在下时：

- 英文和中文各自保持单行；
- 两种语言按各自语法断句，不逐词机械对齐；
- 主语言承担阅读主线，辅助语言降低一级；
- 英文字号需要在手机尺寸清晰，不能为了双语整体缩得过小；
- 同一语义卡的入退点一致，但允许不同语言文字长度不同；
- 任何一行超宽都先重切语义卡。

## 明暗底适配

至少定义两个受控变体：

- `darkSurface`：暖白主字、暖金强调和柔和深色阴影；
- `lightSurface`：炭黑/深褐主字和深琥珀强调。

只切换颜色和阴影，不改变字体、字号、字重、基线和断句。亮暖信息卡上不能继续使用白字。每个变体至少检查一张 100% 原尺寸帧和一张手机缩略帧。

## 逻辑重音

强调跟随逻辑，不只跟随音量：

- 核心判断、结论和章节题眼；
- 否定、限制条件、因果和转折；
- 关键数字、时间、专名和行动指令；
- 铺垫后的落点或笑点。

同一字幕卡通常只有一个主强调点。默认字幕不允许临时加粗或描边时，使用强调色、轻微缩放、字距、下划线、标记或音效。

SFX 与文字动作一致：tick/click 对应落位，下划线对应书写，数字/结论可用克制 tonal hit，有空间位移时才用 whoosh。入点误差不超过 1–2 帧。

## 打字效果

只用于搜索词、命令、消息、引语形成、章节问题或题眼。先锁文案，再制作动效。

- 中文可从约 6–12 字/秒起调；
- 英文可从约 10–18 字符/秒起调；
- 按语义短语揭示，不必机械逐字；
- 标点处轻停；
- 对应语音结束前约 0.1–0.3 秒完成；
- 打字声低于人声并削弱尖锐高频；
- 检查漏字、重字、缺字、字体 fallback 和 seek 后错位。

## 封面合同

视频和封面是两套画幅合同。创作者短视频可从以下规格开始：

- 竖版封面 `3:4`，高质量 2160×2880；
- 横版封面 `4:3`，高质量 2880×2160；
- 横版继承已批准竖版的色板、字体、人物处理、光线和材质，但重新排版；
- 禁止把 9:16 视频首帧直接作为正式封面；
- 禁止拉伸或机械中心裁切；
- 不生成独立 3 秒封面视频。

默认风格明亮、温暖、克制。人物优先抠出或放进独立照片模块，不直接铺满背景；人物通常占画面高度约 35%–55%，必须保留头顶、脸、眼镜、下巴、肩部和必要手势。

标题、人物、品牌、系列名和装饰线分别使用安全框，基础内边距约为画面 6%–8%。手机缩略图不可读、文字相互覆盖、人物头部被挡或越界都直接失败。

标题使用项目指定且授权可用的字体；fallback 可用系统自带的 `Lantinghei SC Heavy`、`Hiragino Sans GB W6`、`Heiti SC Medium`。必须实际渲染确认，不能静默回退。

## 品牌 profile

品牌是项目配置，不是不可覆盖的 Skill 常量：

- `brand.enabled=false` 时不显示；
- `brand.name` 必须由项目设置，不提供作者专属默认值；
- `seriesTitle` 仅在当前系列存在时显示；
- 品牌显示区间由项目指定，可全片、章节或片尾，不强制所有视频首帧到末帧；
- 同一时刻只有一套品牌模块；
- 插镜、图解和信息卡不得重复嵌入品牌；
- 模块避开人物、字幕、来源和平台 UI；
- 亮底、暗底分别使用可读变体。

创作者 profile 应使用稳定识别字体、克制字距和低一级系列名；弱化横线细、短、低对比，不成为第二焦点。

## 系列身份门禁

不能只因为作品“看起来像同一类”就擅自添加系列名。inventory 阶段按以下证据判断：

- 用户明确说明；
- 当前项目目录或项目 manifest 的系列字段；
- 已批准的同系列封面、成片或品牌规范；
- 稳定重复的系列标题，而不是单期标题中的偶然词语。

`seriesIdentity.status=detected` 时：

- `seriesTitle` 必须唯一并使用已批准写法；
- 视频与封面都必须出现系列标识，禁止只改封面或只改视频；
- 两处使用相同识别字体、字距、色彩逻辑和层级，但按各自画幅重新排版；
- 视频标识记录显示区间，封面标识使用独立安全框；
- 至少检查视频开头、中段、信息模块、结尾，以及所有封面画幅；
- 标识避开人物头脸、字幕、来源、二维码和平台 UI。

无法判断时使用 `undetermined` 并停止在方案阶段；确认不是系列时设为 `not_series`，不得为了“统一感”临时创造系列名。

## 开头和结尾

短视频默认不插入独立静音封面段。需要首帧识别时，可让封面覆盖约 0.3–0.8 秒并淡出，但人声从 0.00 秒自然开始。

`contentEnd` 由最后一个有效音节和叙事落点决定。默认只保留最后音节后的 1–3 帧自然收束，不留无意静态尾巴、尾静音、冻帧或黑帧。

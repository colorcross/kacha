# 咔嚓本地生产台深度 Review

日期：2026-07-29

## 结论

本轮把生产台从“能填写配置的页面”整理为一条可执行、可预检、可返工的
五步项目创建流程。功能、状态、错误边界、响应式 UI、安全策略和 CLI 等价
入口均已复核。页面负责冻结剪辑合同，不冒充时间线编辑器、渲染器或发布工具。

## 关键问题与处理

| Review 项 | 原问题 | 完成后的约束 |
| --- | --- | --- |
| 流程 | 长期风格与单项目调节混在一起 | 分为素材、风格、声音、效果、交付五步；单项目覆盖不污染风格 |
| 效果 | 129 个效果只能浏览，难以定位 | 支持名称、说明和标签搜索；点击效果直接建立指定位置任务 |
| 预检 | 生成前缺少清晰的就绪证明 | 校验源片、输出目录、字体授权、设计系统和注册效果 |
| 输出 | 平台与输出预设没有完整进入合同 | 生成 container、quality、geometry、aspect、fps 和目标时长合同 |
| 状态 | 修改配置后可能看到旧检查或旧路径 | 任一合同变化立即清除旧预检与旧生成结果 |
| 风格保存 | 同名自定义风格可能被覆盖 | 阻断同名覆盖，要求修改名称后另存 |
| UI | 信息密度高、路径不够清楚 | 左侧五步导航、中间工作区、右侧实时合同；桌面与移动端同构 |
| 安全 | 本地服务缺少完整浏览器安全头 | CSP、COOP、CORP、Permissions-Policy、Referrer-Policy 与防嵌入 |
| CLI | 页面预检没有等价命令 | 新增 `studio preview --request`，与页面共享解析器 |

## 最终工作流

```text
选择并探测源视频
        ↓
选择可复用风格
        ↓
调整当前项目声音 / BGM / Beauty / 密度
        ↓
选择开场并指定“自然语言位置 + 注册效果”
        ↓
设置平台、栏目、语言、输出与目录
        ↓
预检：源片 + 输出 + 字体 + 设计 + 效果
        ↓
生成 production-brief + config + Agent instructions
```

未指定区间只允许在内容、人物安全区、字幕可读性和声音逻辑约束下由咔嚓
专业判断。生产台生成项目后，仍必须继续完成方案、能力探测、真实渲染、
自动技术 QC 和人工正常速度通看。

## UI 与设计

- 1440px 桌面端采用固定步骤栏、主工作区与深色实时合同；
- 390px 移动端改为线性流程，右侧合同自然落到页面末尾；
- 核心操作保持石墨黑，橙色只用于当前选择、落点和风险提示；
- 表单标签、焦点、按钮状态、`aria-pressed` 和实时状态均有明确反馈；
- 移动端实测 `scrollWidth === innerWidth`，没有横向溢出；
- 浏览器控制台实测 0 error / 0 warning。

## 边界

- 生产台不会上传、付费调用、发布或覆盖源片；
- 生成项目不等于生成成片；
- Beauty v2 默认关闭，启用后仍需动态同帧 A/B 人工复核；
- 本地字体、项目素材、密钥和私有音效不得进入公开仓库；
- Figma 文件用于产品设计和迭代，代码中的视频设计系统仍是运行时唯一事实源。

## V6 语义审片扩展

生产台新增独立 `/review` 入口，但没有把配置页扩张成通用 NLE。审片台以正常
速度视频和高影响剪辑决定为核心，显示理由、置信度、建议机制、最简回退和
`accept / adjust / reject`。调整或拒绝必须提供具体原因；在对应时间线修改和
解决证据完成前，session 保持 `readyForCandidate=false`。

本地服务新增受审片包 SHA 约束的媒体 Range 读取、决策原子写入、偏好候选生成
和项目可观测摘要。CSP 只允许同源媒体，服务仍只监听 `127.0.0.1`。偏好候选
不会自动激活，接受决定不会授予发布权限。实现与命令见
[`INTELLIGENT_EDITING_V6.md`](INTELLIGENT_EDITING_V6.md)。

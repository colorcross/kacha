# 音频回退与安装链深度复审

本轮覆盖 MiniMax BGM/缺失 SFX 的 Agent 执行入口、费用记录、音效导入、双端安装与恢复。
用户已暂缓真实生产验收；本轮不发起付费生成、不上传素材、不公开发布。

## 发现与修复

| 问题 | 修复 | 验证 |
| --- | --- | --- |
| 新合同只有文档链接，模块路由/紧凑包和规则检索没有直接提供，可能漏读 | 增加 `audio_generation` 模块，BGM/SFX/MiniMax 路由带回退合同；紧凑包保留必需合同；新增决策规则 | 完整/紧凑路由、economy packet、规则查询 |
| SFX 规则无条件 `no_sfx` 回退，与必需声音不得省略冲突 | 仅允许已授权的可选声音省略，必需声音报告缺口并阻断 | 检索规则回归 |
| `--verify-only --apply` 能跳过 bundle 测试并安装，上一轮文档同步也使用了此组合 | 禁止参数组合；安装通过完整 bundle 验证后再替换 | 拒绝时连目标目录也不创建 |
| 旧目录移到备份后、新目录激活前出错，没有进入撤销记录 | 首次移动前建立撤销记录；两端失败回滚；回读摘要不符也回滚 | 首端、次端、首次安装、摘要失败四种注入故障及正常备份 |
| 私有 overlay 保护只在包装入口，直接脚本可移除或替换为其他 ID | 底层在安装锁内校验每个目标的 overlay 身份 | 直接脚本缺失/不同 overlay 均阻断 |
| 私有音效导入没有限制目标路径、完整事务锁，批次身份可重复 | 限制库内路径、拒绝符号链接、批次 ID/目标冲突，读改写全程持锁，独占预留输出 | 路径穿越、普通/悬空符号链接、锁竞争与批次重复 |
| 生成 provenance 被丢弃，元数据分步写入失败后可能留下半套库 | 保存生成渠道/逻辑素材/提示词 SHA 与附加证据，冲突阻断；失败恢复元数据并清理新增音频 | 实际 WAV 导入/复用、原件及工作副本 SHA、故障回滚 |

同时移除新增私有来源记录中写死的历史“确认日期”，使用实际登记日期，避免伪造权利确认。

## 工作流补全

- 浏览器连接器故障与网页故障分开判断；必要时用原生界面操作原登录会话。
- BGM 进入音乐创作并选择无歌词/纯音乐；音色设计与 TTS 不冒充独立 SFX 生成。
- MiniMax Design 保留既有草稿和运行任务，不顺便升级；防止通用 Agent 扩展为整套视频制作。
- 对接现有 `cost reserve/approve/consume/reconcile/refund`；远端任务失败不等于未扣费。
- 网页声贝、桌面额度与 CLI 货币费用分别留证，未知金额不记零，没有依据不换算。
- 音频不进入要求视频流的 `generated-cache` 执行器；已冻结工程不自动换运行包。

## 验证边界

专项测试 `tests/audio_fallback_review_tests.mjs` 包含 15 项行为回归，使用隔离临时目录、
合成短音频和故障注入，不调用外部生成服务。该套件已加入 `make check-full` 与安装
bundle 验证；旧 reference router 和 installed identity 回归继续保留。

实际只读观察确认本机 mmx 1.0.19 的音乐帮助可读取、已有音频网页会话可访问、
MiniMax Design 可打开。网页首页默认提供语音合成，音乐需进入单独入口；未据此
声称独立 SFX 功能、生成质量、下载完整流程或生产收益已验收。

双端安装使用 `sync_skill_installs.mjs --apply` 的完整 bundle 验证；静态检查、
job reliability、MCP 和 workbench distribution 另行执行。以本轮保存的命令日志、
安装报告及安装后摘要回读为实际完成依据，不用历史测试替代当前验证。

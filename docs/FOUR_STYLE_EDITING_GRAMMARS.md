# 四风格剪辑语法合同

四套风格共用人物保护、字幕、字体、品牌常驻、对比度和声画同步门禁，但不共用
镜头组织。风格选择先看叙事结构，再看材质；仅更换颜色、圆角、网点、像素边或
玻璃质感，不构成风格切换。

权威机器配置位于 `config/design-system/visual-languages.json`。本文件解释人的
剪辑判断；每份效果合同必须携带同源 `editingGrammarContract`。

## 决策表

| 风格 | 基本时间单位 | 空间组织 | 主转场 | 声音结构 | 不适用时回退 |
|---|---|---|---|---|---|
| 浅暖轻浮层 | 一个完整口播意思 | 画面边缘旁注 + 负空间 | 干净切、匹配切、短淡化、局部揭示 | 默认安静，重大旁注一次轻纸张或空气声 | 普通字幕或干净切 |
| 空间光路 | 一段真实关系或路线 | 固定世界坐标 + 前中后景 + 遮挡 | 遮挡穿越、光路延续、焦点转移 | 起点与终点共享一条方向性 tonal phrase | 浅暖流程旁注或干净切 |
| 幽默漫画 | 铺垫—期待—反应—包袱—回扣 | 主分格 + 反应插格，分格顺序代表时间或反差 | 硬切、停格、smash insert、分格 snap | 沉默是节奏；动作后最多一枚干燥短音 | 浅暖轻浮层或普通字幕 |
| 像素风 | 输入—处理—状态—结果 | 固定整数网格 + 状态寄存器 + 单一活动光标 | tile swap、cursor commit、state replace | 真实状态变化才有对应 UI 声 | 浅暖信息卡或干净切 |

## 浅暖轻浮层：连续编辑旁注

1. 真人口播保持连续，优先完整保留一个意思。
2. 画面先出现问题，再从边缘或视线反方向加入一处主旁注。
3. 证据只占第二阅读区；不能形成居中三卡堆叠或网页弹窗墙。
4. 强调缩放不超过 103%，至少 45% 的可读停稳时间没有装饰运动。
5. 退出顺序是次级证据、主旁注、干净真人画面。

原创图形母件：`assets/design/original/editorial-margin-notes.svg`。

## 空间光路：单次空间导航

1. 先建立固定世界坐标和纵深，再画关系路径。
2. 路径到达后镜头或焦点才移动，节点必须停稳后再前往下一目的地。
3. 文字锚定在具体景深，可从人物后出现；不能漂成平面卡片堆。
4. 关系没有改变时优先一个空间 pass；切镜落在遮挡或空间边界。
5. 起点、路径和终点是一条声画短句，不给每个粒子和节点逐个配声。

原创图形母件：`assets/design/original/spatial-route-field.svg`。

## 幽默漫画：喜剧时间而非漫画滤镜

1. 铺垫先讲清，保留半拍期待。
2. 用硬切、反应插格、停格或尺度错位揭示反差。
3. 一个语义拍只落一个主包袱，文字晚半拍出现。
4. 包袱后留反应时间；需要回扣时再复现同一构图元素。
5. 没有真实反差、误会、尺度错位、反应或回扣时，不使用分格超调和喜剧声。

原创图形母件：`assets/design/original/comic-beat-panels.svg`。

## 像素风：确定性状态机

1. 先声明输入，再显示规则或处理过程。
2. 每次只提交一个真实状态变化；未变化的模块完全静止。
3. 结果必须可验证，奖励、失败、计时和确认都有真实事件来源。
4. 人脸、证据、二维码、来源与正式文字保持高清抗锯齿。
5. 没有状态变化的说明拍保持干净真人画面，不加扫描线、随机 glitch 或游戏 HUD。

原创图形母件：`assets/design/original/pixel-state-lattice.svg`。

## 生产门禁

- `design validate` 要求四个 `grammarSignature.id` 唯一，并逐对比较七个语法轴；
  共享超过一个轴即判为换皮失败。
- `contracts validate` 要求 960 份合同都携带完整 `editingGrammarContract`，同一风格
  不得出现多个签名，四风格不得共用签名。
- 全量图库 QC 同时检查 render evidence、manifest 与合同的语法签名，并禁止跨风格
  完全重复峰值帧。
- 峰值帧只证明空间结果；真正成片还要检查时间顺序、停顿、切点、声音与回退。

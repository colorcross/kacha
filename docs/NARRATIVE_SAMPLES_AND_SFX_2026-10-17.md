# 叙事样片与程序音效：实施与 Review

## 目标与取舍

采用同内容少量候选比较、视觉叙事配方与确定性短音效，帮助确定局部表达方向。复用咔嚓的 jobs、主机编码资源锁、telemetry、Timeline IR 和旧工程保护；不增加第二条主时间线或新模型服务。

参考来源、使用方式、输入格式及边界集中在 [能力合同](../references/narrative-samples.md)。上游仅提供工作方式启发，本次渲染、UI、版本绑定与 DSP 均独立实现，没有运行上游安装器或引入它未提供的渲染/音效引擎。

## 已实施

- `samples recipes/render/status/select/attach`：步骤、证据对比、事件时间线；每份内容生成全局并列、逐项聚焦两份 MP4。支持通用 / 大灰AI，横屏 / 竖屏。
- 根据文字量约束阅读时长，检查真实字体授权、字形覆盖和排版；拒绝缺字、溢出与静默替换。生成只做本地流式帧编码，不保存整套临时 PNG。
- 样片绑定内容、字体及注册表、实现、渲染依赖版本、输出 SHA。选择持久化并带版本条件，防止多窗口互相覆盖；选择不是审片审批。
- Studio 新增“样片”入口；六页导航一致，原生视频比较、键盘选择、单个媒体播放、离屏与后台暂停，已有目录恢复，失败状态说明。
- 读取时间线后自动绑定版本，显示画幅、帧率与时长；插入产出同目录新候选，检查整帧、边界、帧率和画幅，清除旧审阅状态。
- `sfx synth/status/attach`：click、pop、chime、whoosh、impact；48 kHz 双声道 WAV，固定种子，时长/音高/峰值限制与边缘淡化。必须记录触发与现有库检查理由。
- 音效通过现有解码器实测 20 ms RMS 峰值，再用既有 Timeline IR 对齐与混音；保留人声/BGM政策，拒绝尾音越界、重复落点和过期源。
- 两份候选的实际编码次数、渲染秒数与耗时进入现有 telemetry。无新增包依赖；本地合成没有模型请求和 API 费用。

## Review 中修复的问题

1. 原生播放器无法发送 API 自定义请求头：媒体读取独立采用同源和跨站限制，并保留产物身份检查；真实 Range/HEAD 语义由现有媒体服务处理。
2. 两个候选同时请求元数据可能争用同一根目录锁：同包并发读取共用一个正在进行的核验，完成后不缓存，后续请求重新核查。
3. 内容或包路径改变后的延迟响应可能覆盖当前页面：使用请求代次隔离，立即清空旧选择；失败读取不能保留可误用的旧候选。
4. 多窗口改选可能丢失先前更新：保存时校验当前选择摘要，冲突要求重新读取。
5. 默认细字重与竖屏双栏缩小影响阅读：优先注册表中的常规/中等字重，提高正文尺寸，竖屏维持独立比例，步骤和时间节点增加序号。
6. 读取已有音效后表单可能显示旧参数：按已验证回执恢复音效参数，并给媒体读取失败提供明确反馈。
7. 文件仅更新时间戳时，回执中的旧文件状态会使媒体服务一直拒绝读取：核验内容 SHA 后取当前文件身份，再由打开的文件描述符检查读取期间变化。
8. 样片渲染未显式记录渲染工作量会被默认记为零：现在记录两次编码及两份候选的总秒数，专项测试核对 telemetry。

9. 极短低频音效的加窗去直流补偿不足，留下可测偏置：按实际窗口积分归一化补偿，保持零首尾，并新增最短低音参数的 PCM 均值检查。

## 验证与验收边界

自动验证覆盖：固定种子音效字节一致、非静音与峰值边界、字形缺失、未知字段、短阅读时间、后台真实 MP4 生成、候选差异、过期/并发选择、旧源保护、时间线插入、组合片真实渲染与原音轨保留、媒体并发/Range/跨站/版本检查、文件与回执篡改阻断。新增套件已加入 `check-specialized`、`check-full` 和双 Agent 安装验收。

浏览器检查覆盖：键盘选择、内容修改失效、迟到结果隔离、失败恢复、六页导航、移动端宽度，以及三种中文配方的真实播放、五类音效中的代表 WAV 播放和 UI 时间线插入。完整技术回归与部署结果以本次交付回执为准。

演示使用明确标注的合成内容，不代表实际节目事实。三类信息卡不是完整三维/数据图表引擎；五类抽象音效不是任意语义环境声生成。候选正常速度完整审阅、手机与耳机听感、真实节目创作质量及发布放行仍是独立验收。本次不修改 MiniMax BGM 网页默认入口、MiniMax Design 音视频默认入口或现有项目的私有素材分发边界。

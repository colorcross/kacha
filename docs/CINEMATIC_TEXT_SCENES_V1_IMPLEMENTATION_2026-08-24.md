# 行者大灰动态字景 V1 实施记录

日期：2026-08-24
状态：代码、配置、文档、示例、自动回归、合成样片与双端 Skill 同步已完成；真实当期视频人工验收待有源素材后执行。

## 1. 本轮目标

把“字幕是设计图层，不是普通外挂字幕”落实到咔嚓现有生产链，覆盖文字包装、字体职责、图形母题、比例、动效、人物前后景、逐字进度、栏目差异、失败关闭和交付验收。

## 2. 已实施内容

- 将口播字幕系统升级为阅读、语义、空间三级；
- 新增 `editorial_stack`、`edge_annotation`、`quote_field`，布局总数由 7 增至 10；
- 为工具分享、解读好书、有限的无限游戏、灰常AI、闲聊建立独立副色、图形母题和运动性格；
- 在事件计划中冻结展示、阅读、辅助三类字体文件、授权状态和 SHA-256；
- 增加无描边、无底板、回声透明度、强调面积、旋转角度和锚点约束；
- 增加 `micro_rail` 歌词/逐字进度，要求真实、单调、cue 内的 `words` 时间，禁止整行卡拉 OK 变色；
- 增加语义/空间字景密度评估与 `--strict-text-scenes` 生产门禁；
- 渲染器实现栏目图形母题、题眼/注释/引语层级、阅读基线和人物后景偏置；
- 渲染 manifest 写入栏目、层级、三类字体、逐字数量、密度和人工验收要求；
- 预制效果模板由 62 增至 65，并重建受设计摘要变化影响的样式帧与示例合同；
- 新增完整设计规范和五栏目 cue 示例。

## 3. 实施中发现并修复的问题

1. 术语布局曾因文本包含“AI/模型”被路由到技术细体。已把定义、引语、编辑堆叠和空间题眼锁定到各自展示字体角色。
2. 后景题眼在中央人物蒙版后可能全部消失。已依据左右锚点偏置，并提高后景题眼尺度，使遮挡关系可见。
3. 无本地字体注册表的隔离测试中，辅助字体 family 可能为空。已增加来自字体路由合同的确定性 family 回退；生产项目仍优先使用授权文件，缺文件/哈希漂移继续阻断。
4. 字幕注册表变化使旧设计 digest 和样式帧 manifest 失效。已重新渲染并更新引用 SHA，没有放宽失效检查。
5. 合成样片最初放在仓库 `.work`，隐私扫描发现计划含 macOS 用户绝对路径并阻断安装。已把完整证据迁移到仓库外项目工作区，保留扫描门禁。
6. 旧布局和 Python 渲染器曾通过字符串切片静默截掉超长文字。现由计划器统一执行全部布局字数合同，渲染器不再截断；超限直接阻断。
7. 非法数值可在 JSON 序列化后变成 `null` 并绕过部分范围检查。现对透明度、旋转、视差、脸部间距、入场帧、缩放和进度线参数执行有限数值与范围校验。
8. 旧验证只核对部分密度计数和布局注册表。现冻结字体路由、设计解析输入、生成选项、源/蒙版媒体身份，并从冻结转写和当前注册表重建事件、展示文字、字景、逐字时间、声音与密度；重算 digest 不能为篡改放行。
9. 蒙版过去只验文件哈希。现同时冻结并核对尺寸、帧率、时长、帧数和起始 PTS，短蒙版或错轴蒙版在计划阶段阻断。
10. 自定义 `entryFrames` 过去没有驱动真正的可见落位和 SFX 峰值。现显式记录 `entryStartFrame / visibleLandingFrame / sfxPeakFrame`，三者与渲染入场及实测音效峰值对齐。
11. 严格模式过去仍可能接受系统字体或错误字体家族。现要求冻结的项目授权字体注册表，并对金陵体、华光标题黑和思源细体逐角色核对真实文件、SHA 和授权；禁止静默 family fallback。
12. `footage` 表面无法证明亮暗适配。正式字景在严格模式下必须显式标注 `light` 或 `dark`；亮底使用独立深色栏目强调色，避免浅青、浅金或薄荷绿失去对比。
13. 横屏辅助字与阅读字幕在手机宽度下偏小。现按横竖画幅使用不同字号比例，并以真实字体测宽阻断为了塞入安全区而过度缩字。
14. 非严格渲染 manifest 曾把严格检查写成“已要求”而容易误读。现明确区分 `pass` 与 `not_run_required_for_production_delivery`，不再把合成样片冒充生产门禁通过。

## 6. 双端安装状态

执行：`node scripts/kacha.mjs install sync --agent both --apply`

- Codex 与 Claude 均由只读 `install status --agent both` 回读为 `current`；
- 同步器在无私有路径的临时安装包内再次执行完整测试后才完成原子替换；
- 每次同步都会生成新的 bundle digest 和带时间戳备份目录。为避免安装包把自身
  digest 写入自身形成自引用，本记录不固化这两个易变值；以同步命令的机器可读
  输出和最终只读 status 为准。

## 参考证据

CLI 读取均返回 HTTP 412，没有获取到可解码的参考视频，因此没有逐镜观看、听觉

不以博主姓名给模板命名，不声称复制了其完整剪辑风格。

## 现有问题与实施

| 问题 | 实施 |
| --- | --- |
| 单项效果多，跨镜头叙事模板不足 | 新增 4 套段落模板，绑定 12 种手法与现有视觉模板 |
| 导演计划主要按关键词评分分配强调 | 显式内容信号优先，栏目只是无信号时的待复核默认 |
| 首个语义拍始终被强制为高影响 | 主开场仍只有一个，但允许干净的动作、声音和人物开场 |
| 结果、反应与自然声可能再次被包装打断 | 全局保护优先于模板偏好，减少装饰强调并给出声音意图 |
| 安静预算只计次数，短片可超比例 | 同时按实际影响秒数和次数分配，不分配超过可用时长的强调 |
| 阅读时长缺少内容与完整落位时刻 | 以实际屏幕文字及落位偏移估算，区间不足列问题，不自动改时间轴 |
| “动作切/J-cut”等名称易被误当已执行 | 返回必需证据、候选状态、回退与执行边界；缺真实 handle 不放行候选 |
| 手法只存在长文档中，弱模型不易调用 | 增加 `templates recipes`、`intelligence recipes` 与渐进 reference 路由 |
| 专业规则可被重新计算 digest 后伪造 | 导演计划从源 cues 和当前注册表确定性重建验证 |

4 套模板：实验与证据推进、AI 与工具操作演示、沉浸式现场记录、观点与思考留白。
后者用于将克制的节奏移植到解读好书与闲聊，保持行者大灰 V3.3 五栏目体系。
字体、五套视觉语法、品牌封面和项目私有音效许可保持既有合同。

## 已实现与尚未证明

- 已实现：可查询模板、语义路由、手法候选、缺证据回退、阅读/反应/现场声保护、
  时长预算、导演计划与审片入口的联动、确定性验证。
- 既有渲染能力继续使用：Timeline IR、Render Graph、字幕、呼吸、图形、BGM/SFX。
- 新模块不自动剪出素材中的动作相位，也不自动生成 J/L 独立音轨或环境声；这些
  都要求真实素材、实施和正常速度审片。没有把手法建议数量记为新渲染效果数量。
- 原有 V6 计划需从当前 cues 重新生成；配置版本提升为 6.1.0，旧计划不会悄悄
  继承新规则下的通过状态。
- 未证明：三位博主逐镜风格、真人节目的审美提升、完播提升或效率量化提升。

实施指南：[professional-editing-craft.md](../references/professional-editing-craft.md)。

未知模板、篡改后的确定性重建和短片时长预算。最终运行证据另存本地 review 目录。

# 幽默漫画视觉语言与动效合同

## 定义

“幽默漫画”是成年编辑漫画语言，不是儿童卡通、表情包墙或固定搞笑模板。它用
真实叙事中的反差、预期反转、尺度错位、反应时机和视觉回扣制造幽默；真人脸、
事实证据和来源仍保持摄影真实性。普通说明段没有笑点时，只保留清楚的漫画分格
与墨线秩序，不强行夸张。

## 适用与禁用

适用：自嘲、误解与纠正、观点碰撞、前后反差、失败复盘、荒诞但真实的流程、
轻量类比和有明确反应点的开场或转场。

禁用：严肃创伤、疾病与事故当事人、未经证实的嘲讽、普通事实陈述、需要完整
读取的复杂证据，以及任何会把真实人物变成被羞辱对象的场景。

生产选择必须命中至少一个可核验信号：反差、误会与纠正、尺度错位、反应、回扣
或自嘲；合同同时记录命中的信号和素材证据。没有信号时自动回退
`xingzhe-light-overlay`，安静说明段不得为了维持风格而硬造笑点。

## 视觉合同

- 保留原实拍底图；漫画化只进入局部分格、暖纸、炭黑墨线、局部网点、反应框、
  短对白气泡、速度线和冲击星芒。
- 同一语义拍最多一个主笑点、三格可读分镜和一处网点区域；网点总面积不超过
  18%，反应小窗不超过画面 22%。
- 对白气泡最多 12 个汉字；长内容回退信息卡或普通字幕。
- 色彩以暖纸、炭黑、暖橙/珊瑚红为主，理性蓝负责关系和证据；不使用全屏
  高饱和爆炸色。
- 正式字幕继续使用金陵体、无底色无描边、60% 阴影；标题、术语和金句继续
  使用华光标题黑。漫画感来自构图与图形，不更换未授权漫画字体。
- 真人面部、眼镜、证据、二维码、来源和平台 UI 不套漫画滤镜，不被速度线或
  气泡遮挡。

## 动效合同

- `entry`：需要夸张时先有 2–4 帧预备动作，再用 4–8 帧完成主动作；一次
  103%–108% 超调后用 4–6 帧停稳。没有笑点的说明模块不用超调。
- `hold`：笑点成立后留半拍反应时间；文字、网点、速度线和分格边界保持稳定，
  不循环摇晃。
- `exit`：按装饰、说明、主反应框的逆层级在 6–10 帧内撤除，并在下一主信息
  前完整清场。
- 每个效果仍以真实语义重音为峰值，声画误差不超过 2 帧；同一时刻最多一个
  主效果。
- 低能力回退为一次局部强调、干净分格或普通信息卡，不回退为整块漫画贴图。

## 音效合同

- 声音母版：`humor-comic-dry-editorial`。
- 优先从项目音效库按真实触发选择 `pop / motion / turn / awkward / question /
  info / knowledge`；使用干燥短促 pop、纸张 flick、短 sweep 或克制尴尬声。
- 音效峰值只对齐可见动作完成帧；问句尾音、笑点尾字和口播辅音优先保护。
- 禁止笑声轨、连续卡通轰炸、普通重点配枪声，以及先响后动。
- `impact_literal` 只允许真实画面与口播都存在明确强动作，或用户批准的非现实
  漫画桥段；不能作为通用强调。

## 240 项效果应用原则

- 字幕与品牌：只改变墨线、局部纸张和一次轻入场；普通字幕无音效。
- 标题、定义、金句：使用非对称漫画分格和一处局部网点，主结论最后落位。
- 信息卡、流程与数据：逐项建立；当前项可以形成反应格或冲击线，非当前项保持
  像素稳定。
- PIP、分屏与人物后文字：利用分格和遮挡建立信息差，不把同一画面重复缩小。
- 开场、转场和镜头运动：只有真实反差、方向或反应点成立时使用预备—动作—
  停稳；普通连接保持干净切。

## QC

必须检查：幽默机制可说明、真人与证据仍可核验、没有幼龄化/羞辱化、没有表情包
墙、气泡文字不过长、主笑点唯一、网点面积受控、进入/停稳/退出完整、音效不盖
尾字、横竖版独立构图、手机尺寸可读。图库门禁还必须从人物蒙版实测头脸像素未被
包装层改写，并校验网点实占比、常驻品牌尺寸与动效合同中的选择证据。

完整横竖峰值帧位于
`设计参考/行者风高保真样板/全量效果库_v4_幽默漫画/`；每个效果的正式时间行为
以 `config/effects/motion-contracts/design-effect-library-v3.json` 中
`xingzhe-humor-comic` 合同为准。

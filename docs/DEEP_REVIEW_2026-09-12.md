# 咔嚓专业剪辑深度复查与修复

范围：在 `0c5817c` 的四种段落模板、十二种专业手法基础上，复查 cues 输入、导演
预算、素材缺口、审片合同、偏好学习和本地审片呈现。保留原素材、现有渲染路径和
生产门禁；本轮通过 CLI、本地 HTTP、FFmpeg 和独立安装验证，不使用浏览器。

## 问题与已实施方案

| 问题 | 复现与影响 | 修复 |
| --- | --- | --- |
| P1 错误置信度被升级 | `confidence: "unknown"` 被转换为 1，错误标注可参与风格决策 | 只接受 0–1 的有限数字；同时校验 cue 对象、ID、signals、craft 和已知证据键；保留数字型 ASR ID 兼容 |
| P1 开场事实漏掉真实来源要求 | 首拍先标记为 hook，fact/data 可漏掉素材需求；screen_demo 被当作 illustrative | 叙事位置与事实需求独立判断，开场、测试结果、对比、操作链都保留 factual 来源约束 |
| P1 生成素材可充当事实依据 | 文件存在、许可和来源字段齐全就能被认为可用 | factual 与真实身份素材排除已声明生成许可、生成器、合成来源；合并来源逐项检查 |
| P2 空白区间抬高包装额度 | 100–101 秒与 200–201 秒两个 1 秒片段，被算作 201 秒的预算，旧版允许两次强调并报 99% 安静比例 | 只按有标注的区间覆盖计算强调额度、频次和安静比例；空白另列 unannotatedSeconds |
| P2 拆分 cues 改变整片模板 | 30 秒演示与 10 秒旅行，旅行拆成十段后旧版选现场模板 | 以显式语义覆盖时长评分；一个 cue 的重复信号只记一次，栏目只作平局选择 |
| P2 现场声建议无依据 | ambient_sound 未标注可用录音仍建议前景现场声 | 需依据、置信度、时长及候选资格同时满足；否则保持同期声，不提出未经确认的现场声处理 |
| P2 三候选上限掩盖缺口 | 五种手法同时触发，旧版只检查前三项，漏掉现场声和阅读证据 | 全部匹配项均检查；展示与安全检查分离，暂缓项仍进入 issues |
| P2 阅读时钟污染其他停留 | 2 秒片段中，文字在 0.6 秒落位会错误扣减现场声可用时间，旧版误报不足 | 阅读、反应、现场声分别计时；不自动改源区间或重复帧；无阅读信号的文字时间标注进入审片 |
| P2 目录与模板关联校验分叉 | 只有 recipes 入口检查手法引用；章节换挡引用主开场模板 | 所有目录入口共用完整合同校验，核对真实模板 ID 与默认模板；章节使用干净切 |
| P2 审片身份和学习范围不完整 | 单拍内容不变、阅读要求改变时旧 sourceDigest 不变；主动停用的手法仍产生偏好 | 摘要绑定手法、缺口、目录；规划手法与停用决定不进入风格学习；已有真实叠加的学习保留 |
| P2 计划被当作执行证据 | director 的 `validate-plan --for-execution` 旧版返回成功 | 明确拒绝把尚未编译的导演计划作为执行证明；普通计划验证与实际渲染门禁保持分工 |
| P2 审片建议不可读 | 专业手法嵌套 JSON 直接显示，难以发现缺口和修复动作 | 用纯文本显示手法名称、状态、各项可用时间、修复建议与候选边界，避免 HTML 注入；HTTP 验证模块路由与 MIME |

## 产品判断

应继续让咔嚓的“专业”体现在内容依据、镜头连续性、信息可读与声画处理上。
本轮把规则变成可检查的逐拍合同，并让审片人能直接看到待解决问题。新增更多
风格名字或过渡动画，不能替代真实素材依据与成片复核。

模板自动选择是初稿建议；显式 `--recipe` 仍可覆盖。混合题材节目可以按段生成
不同模板的计划后人工组织，当前不宣称已经实现全片自动分段或 J/L-cut 自动编译。

## 升级

手法目录升级为 `1.0.1`。旧导演计划、依赖它的素材缺口与审片包需要从当前 cues
重建，旧摘要不能手动重签以跳过变更。新规则会暴露过去遗漏的事实来源与阅读
缺口，按清单补充当前真实材料或明确采用干净原镜回退。

本地源码、完整检查、安装包验证与 Codex/Claude 实际安装分别回读。没有公开
发布、推送远端，也没有替真实节目作最终人工审片。

# 美颜移除与剪映交接复审

复审基线：`e1a30823a1d380fb18d66ae4b8a5dea2e242ea33`。

## 发现与修复

1. **旧风格阻断整个工作台。** 旧自定义风格中的 `beauty.enabled=true` 会使整个目录加载失败。现按文件隔离不可用风格，返回名称、路径和原因；界面可展开查看，不改原文件。损坏 JSON、丢失基础风格及重复 ID 同样隔离。正常风格仍能选择；不可用 ID 不能编译项目，不静默替换。关闭旧配置中的美颜后刷新可恢复其他偏好，新配置继续不含美颜。
2. **连续切点转场被误拒。** A→B、B→C 会因 B 被两项使用而被判重复。转场现以有序切点去重；源片增强仍按能力与片段去重。反序、非相邻及同一切点重复请求继续拒绝。
3. **分发验证缺少增强计划专用套件。** 原子安装现在显式执行 `jianying_enhancements_tests.mjs`，与已有专业工具端到端测试共同覆盖计划及回收合同。
4. **工作台文档滞后。** 修正默认风格、历史风格边界、字体与摘要说明；补充不可用风格恢复及连续转场合同。

## 行为验证

- 目录回归同时放入有效、旧美颜、损坏、重复和缺基础的风格，核验可用列表、错误列表、原文件不变与修复后刷新。
- Chrome 工作台回归检查不可用提示不会禁用创建，错误文本不解释为 HTML；既有连接恢复、异步竞态、跨风格输入保持和移动布局继续覆盖。
- 增强计划测试覆盖连续切点、重复切点、反序与非相邻切点；重新计算摘要也不能让非法片段计划通过。
- 专业工具回收测试继续覆盖实际合成媒体、总帧数、音轨覆盖、过期导出、源身份变化和失败隔离。
- 发布仍需 `make check-full`、`make check-browser`、双 Agent 原子安装及安装后实际渲染回读。当前批次的运行日志与交付身份存放在本机 `output/review-followup-2026-10-16/`，不含私人素材的发布包保持独立。

## 能力边界

内置美颜实现和入口仍不可用；剪映能力目录是待实际操作的任务合同。合成媒体、操作记录校验和正常技术回收不能证明真人美颜或人声降噪质量。此前真实剪映窗口控制失败、会员权益未证实的限制，本次代码复审不将其标记为已解决。真人增强必须另以当前 UI、真实片段 A/B 和正常速度审片验收。

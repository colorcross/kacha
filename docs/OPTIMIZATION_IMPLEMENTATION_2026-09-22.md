## 本轮工程测量

- 入口文件字节数减少约 87%。这是入口大小对比，不是所有任务必要参考量或真实 Token 的降幅。
- 转场工程样例从 5 个 EDL 片段选取 2 个参与局部渲染；完整/局部音频相关系数约 0.999994。另对移动 overlay、SFX 尾音、BGM 淡变和静态帧差进行对照。不能据此声称真实节目等待时间降低了多少。

## 边界与恢复

- 现有工程不自动降门槛或迁移。新版源项目的空需求模板不能通过计划门禁，须由 Agent 根据实际内容补全；用户不需要填写 JSON。
- J/L 自动编译仅限本版已验证的单源、硬切、无独立 dialogue stem 组合；需要足够 handle 和完整画面遮盖。复杂转场或已分离人声先建立映射，不自动猜测。
- 有状态 sidechain 预览会保留必要的片首音频历史并报告扩大范围；不宣称所有预览都只处理目标几秒。
- 网感局部合成当前支持 SDR 8-bit 4:2:0、方形像素、无旋转。复杂高位深、HDR、alpha 组合未放行；原渲染入口保留。全效果库原生编译没有完成，也不属于本版承诺。
- 固定包不打包模型、私有字体和项目音效。外部依赖仍按原合同核验；包或工具链变化需显式新绑定，不能静默升级。
- 工程重试与缓存命中不替代事实、许可和质量审查。失败任务走现有 jobs 恢复；付款未知不重提；源和批准版本不覆盖。
- 本轮不包含公开 push、CI/Pages 部署或真实生产收益结论。

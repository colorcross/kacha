# 咔嚓开放创作方向 V2 · 2026-10-23

## 结论与取舍

四套创作 skill 增加的是镜头、图解、动画与短片的制作能力。咔嚓继续承担素材事实、语义精剪、原声保护、时间线、候选版本、授权与交付审阅。不能用“有动画工具了”推导出“不需要剪辑语言”。应删除的是互相重复的产品选择和把外观当作全部表达方式的框架。

| 原定义 | 本次处理 | 保留的价值 |
|---|---|---|
| 清朗知识、沉浸阅读、现代科技、沉静纪录 | 从新建选择与自定义基础选择退出；保留兼容解析 | 旧工程重现；新作品按具体内容自由组合 |
| 浅暖轻浮层 | 作为重点旁注的一种旧配方 | 完整意思、留白、旁注时机 |
| 空间光路 | 作为关系与机制的一种旧配方 | 关系结构、焦点和观察顺序 |
| 幽默漫画 | 作为喜剧节拍的一种旧配方 | 铺垫、停顿、反应、回扣 |
| 像素风 | 作为状态变化的一种旧配方 | 输入、规则、变化、验证 |
| 暗黑科技 | 作为证据揭示的一种旧配方 | 基准、证据、判断与不确定性 |
| 通用、大灰AI品牌包；历史行者风兼容包 | 前两者用于新建，行者风另设历史入口 | 字体、品牌与栏目证据约束，不替代艺术方向 |

五套旧风格均退出普通新建流程，统一放入显式历史兼容入口。历史配置与渲染器只服务旧工程重现；新导演逻辑不再通过旧外观选择表达方法。

## 更开放的表达

注册表提供连续表达、重点旁注、关系与机制、操作演示、比较与数据、证据揭示、喜剧节拍、状态变化、蒙太奇与声音桥、情绪与艺术场景及自定义入口。目标预设只用于起步；方法、画面与执行工具分开。注册表允许扩展，单个项目也可写自定义方法。

例如产品实测可用“连续操作 → 分屏比较 → 局部放大证据”，配真实录屏与手绘注释；读书可用“完整论证 → 书页证据 → 关系图”，不必沉浸暗色；运动短片可围绕环境声、动作匹配与呼吸变化，不必增加科技元素。以上是创作方案示例，不是已完成的实拍案例。

四套工具不按一种画风绑定：同一个发布片可以用 huashu-motion 做排版和产品镜头，用 huashu-art-motion 表达机制，再回到真实录屏；huashu-design 可制作需要逐步展开的图解；具有独立镜头和声音结构的片段才考虑 lemo-opuscar。原声、素材出处和候选版本均回到同一工程管理。直接可用的请求结构见 `examples/creative-direction-request.json`，内容须按实际素材替换。

## 已实施范围

- 新增开放注册表、校验与确定性方向计划命令，记录方案摘要与注册表指纹。
- 工作台将品牌与方向分开，支持目标、内容要求及自由画面参考；视频编译将方向写入 brief、配置与 Agent 指令。
- 文稿/选题入口支持表达要求与画面方向，创建内容工程时保留对应方案和指令。
- 多素材入口把方向绑定到冻结 brief、配置、分镜要求和导演计划；遗漏或没有镜头覆盖的显式方向不能进入候选。
- 导演按实际内容信号提出方法，未匹配则保留原素材；无固定模板的自定义品牌也可形成方向计划。方法候选不代表素材已经核实。
- 通用包取消固定开场秒数、真人/真实画面占比、统一留白比例及固定卡片面积/停留上限，支持有说明的自定义镜头机制；大灰AI栏目约定独立保留。
- 五套旧风格标为 `compatibility-only`，从新建列表和新建风格的基础选项过滤，旧 ID 仍能解析。
- 四套 skill 为可检查的执行候选；不会因选择目标自动渲染或授权付费。
- 官网相关表述从“五种风格”改为“从内容选择表达”，五张示例卡只展示五个可复用方法；其他方法与自定义方向在正文说明。

## 验收与边界

需验证：自定义方法、非法请求阻断、方案指纹、工具状态诚实表达、视频编译保留方向、文稿工程保留方向、旧项目兼容、官网构建及工作台交互。实际命令结果另记于本轮验证记录。

此轮并未提供实际新节目素材，因此不声称完成新风格实片验证。旧效果的 1200 组/2400 帧审计只属于旧兼容资产库；不能用来证明开放方向的艺术质量，也不能把方法数量当作自动可用的模板数量。既有冻结工程不自动迁移；新增多素材入口已接入方向约束。

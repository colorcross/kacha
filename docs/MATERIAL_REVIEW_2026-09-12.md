# 多素材成片深度复查与修复

本轮沿输入、抽帧、分镜、后台执行、归一化、字幕、成片与状态回读检查。保持
Agent 根据实际素材组织叙事、Timeline IR 执行最终合成、本地候选与人工审片
分开的产品边界。没有修改源视频或私有音效，也没有进行公开发布。

## 发现与解决

| 问题 | 实际影响 | 修复 |
| --- | --- | --- |
| 重复抽帧重写证据身份 | 同一分镜无法继续；补帧影响已完成版本 | 相同内容不重写；按摘要保存不可变快照，分镜引用自己的快照 |
| 已存在的预览被盲目采用，空图片证据被接受 | 损坏或无归属文件可能冒充审阅帧 | 核对素材、路径、帧时间及文件身份；拒绝空、变化和无归属证据 |
| 分镜的未知字段被忽略 | `speed: 2` 被接受但视频不变速 | 分镜、要求、镜头和配乐逐层检查支持字段，明确报错 |
| CLI 不检查多余或重复参数 | 拼错参数仍显示成功 | 按子命令检查允许参数、重复项和缺失值 |
| 允许目标时长差一帧 | 拼接母版与最终 EDL 发生短尾或超长 | 逐镜量化后要求总帧数与目标一致 |
| 非方形像素直接套方形像素 | 画面被横向拉伸或压缩 | 抽帧和归一化先恢复显示比例，再适配或裁切 |
| 计划目标未与原始要求比较 | 重算摘要后能改变冻结输出尺寸 | 每次读取活动分镜核对 target 与 brief |
| 渲染在加锁前读取分镜 | 排队版本检查存在竞争窗口 | 加锁后读分镜和校验任务摘要，结束再次核对版本 |
| 字体晚到转码后才检查，依赖系统安装 | 缺字体时白跑大量转码 | compose 冻结字体文件与字号，渲染前准备工程字体目录；直接向 libass 提供 |
| 成片状态不校验 QC 内容与部分产物路径 | 失败标志或错配产物仍可显示候选就绪 | 核对记录类型、各项 QC、帧数、人工状态、字体及精确产物路径 |
| 失败清理可能删除预先存在的同名临时文件 | 旧任务中间文件丢失 | 抽帧、片段转码、母版拼接均在创建前拒绝同名文件，错误分支保留原文件 |
| 只看容器时长不能证明视频完整 | 音频长尾可能掩盖视频帧短缺 | 完整解码时统计视频帧，并验证目标帧率和总帧数 |

初始复现确实观察到 `speed: 2` 静默接受，以及重复 inspect 后的
“分镜派生时间或素材身份不一致”。回归覆盖真实 FFmpeg 导出、像素位置、
音量、字体隔离环境、分镜修改及后台取消/恢复，不使用浏览器验收。

## 迭代后的使用方式

用户仍只需给素材和要求。Agent 把不完整要求拆解成可执行分镜，先确认素材与
字体准备好，再提交渲染。错误信息直接指出未知字段、缺失字体、失效证据或
总帧数不符，便于 Agent 自动修正；已完成分镜不因补充审阅失效。

字体、审阅快照和输出均绑定编辑版本。字幕或备注修改可继续复用未变化的
无损片段。工具代码升级会改变归一化缓存键，以免误用旧几何处理结果。
旧运行版本项目按既有规则保留，新安装中建立新项目；旧分镜可重新 compose
以冻结新字体合同，旧候选不能直接冒充新增帧数检查已通过。

## 验证入口与结论边界

- 专项：`node tests/material_project_tests.mjs`，并入既有 V7 回归。
- 公开检出不含私有品牌字体时，专项使用真实系统字体并冻结文件 SHA；
  `--public-font` 可强制验证此分支。私有字体不进入仓库，生产字体配置与检查不变。
- 全量：`make check-full`，含静态检查、任务可靠性、核心、MCP、分发、隔离安装。
- 双端更新：全量通过后经 `install sync --agent both --apply` 原子安装与回读。
- 日志和候选保存在本地 `output/material-review-2026-09-12/`，不打入公开工具包。

本轮合成素材检查证明技术行为，不能替代真人节目正常速度审片、试听或
特定博主风格的艺术验收。技术候选的 `humanReviewComplete` 保持 false。

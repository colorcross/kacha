## 2026-08-10 效果图语义修复

上一版图库虽然通过了数量、文件、碰撞与近似构图检查，但这些检查没有证明“图里画的就是该效果”。复核发现，风格包装器会在部分条目中覆盖效果本身：品牌角标、折线图、PIP、流程图、A-roll、净切、开场标题与缩放等功能效果，被误画成通用卡片、准星或关系图。

本轮将渲染规则改为“效果身份优先于风格表达”：

- 组件、布局、渲染器与动效必须保留自身功能拓扑，风格只能改变材质、色彩、光线、边缘、节奏与声音；
- 只有进入各风格明确允许的场景级语义清单，才可以更换画面结构；没有命中时回退效果专属画法；
- 图像清单与合同新增 `renderPlan`、`visualExecutionPlan`、效果身份证据和场景语法证据，QC 会核对三者一致；
- 为引用卡、信息卡、评分卡、不确定性披露、品牌角标，以及响应同步、语音同步、时间标记、延后进入、结果停留和静止等容易混淆的条目补齐独立构图；
- 视觉拓扑回退不再连带回退声音母版：非场景效果保留自身功能性 cue，但始终服从所选风格的音色、允许触发和禁用声音清单；
- 重新生成全部 2400 张横竖峰值帧与 1200 份合同，并按五套组件、场景、渲染器、布局、动效联系表完成人工复核。

最终机器检查为：1200 / 1200 组语义三元组匹配；跨风格完全重复 0 组；五库同风格未声明近似构图均为 0 组；人物头部碰撞 0；黑块 0；失败与警告均为 0。该结果证明参考图、清单和合同的语义一致性，不替代真实成片的正常速度人工复核。

## 深度 review 后的加固

- 全范围增量不再生成零段预览；固定选开场、复杂视觉和结尾三段待确认样本；
- 分散变化用动态规划最小化总覆盖跨度，只有不可避免的长段才声明预算例外；
- 计划验证从当前 orchestration、cues、delta、policy 和 recipes 重建风险、区间、
  覆盖与调度，重算 digest 不能绕过质量或编码预算；
- 自动执行只接受登记脚本、当前实现 SHA 和参数级输出绑定，并在任务结束后再次
  拒绝符号链接或越界输出；
- 缓存审计重算 contract key，验证精确输出 schema、文件数和当前产物内容，拒绝
  缓存路径符号链接；预热覆盖率改为只统计阶段计划声明的预期内容键，不能用同种类
  的任意旧条目冒充当前命中；
- 效率比较要求真实可解码源片与含音轨输出、不同输出、当前结构化人审/指标/护栏
  文件，以及两边完全一致的八项目 ID；格式正确但不存在的 SHA 不再算证据；
- `status/observe` 每次按当前文件重验，损坏计划成为可恢复阻断，`run` 可安全重建。

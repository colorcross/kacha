# 咔嚓 V6 全面优化实施状态（2026-08-08）

## 结论

本轮已把“智能剪辑”从局部效果选择升级为可验证的全片闭环：先做全局叙事与
注意力预算，再决定素材和效果；候选片必须通过时序感知审计与正常速度语义审片；
偏好只能由明确反馈形成并显式激活；真实质量提升只能由同源人工评测证明。

代码、CLI、本地审片台、生产门禁、中英文文档和官网已同步。旧项目保持兼容，
只有 manifest 明确设置 `intelligenceV6.required=true` 才强制完整 V6 证据链。

## 已实施范围

| 能力 | 生产结果 | 关键边界 |

## 生产门禁

- `gate-plan` 校验 director plan 与 asset gap plan 的 schema、digest 和全片预算；
- `gate-render` 阻断截断素材索引、未物化生成候选、许可/来源未知和未补齐的真实证据；
- `gate-release` 阻断时序 blocker、取消人工动态审片、未覆盖的高影响决策，以及
  缺少真实正常速度预览、调整或拒绝后缺少解决证据的候选；
- `intelligenceV6.required=true` 同时约束 v2 首剪和 v3 增量 manifest；
- V6 不能降低 proposal、Timeline IR、Render Graph、变化层 QC 和 release
  report 的既有要求。

# Current product

> 对账修订：`kacha-human-agent-editing-2026-08-31`。事实源为当前代码、README、
> SKILL、架构文档和本轮本地回归；不代表发布或生产结果。

## 当前目标用户与场景

咔嚓面向使用 Codex 或 Claude Code 的专业视频创作者，首要生产对象是“行者大灰”
真人口播、工具演示、读书与 AI 内容。典型场景包括从脚本或源视频建立项目、
首剪、字幕与动态字景、声音、视觉包装、审片、增量返工和本地候选交付。

## 当前问题与价值主张

产品解决“AI 能生成效果，但缺少可恢复工程、证据链、版权/费用边界和完整验收”
的问题。核心价值不是一键自动成片，而是把人类内容判断与代码化生产门禁连接起来。

## 当前能力、范围与非目标

当前能力包括 V7 四里程碑编排、V8 质量不降级效率、Timeline IR、Render Graph、
统一审片、Agent 控制面、五套视觉语言、电影化字景，以及本轮新增的能力路由、
费用账本、参考片原创化、片段语料、制作飞行记录、Series/Hero 路由和四套工作流包。
其中付费执行采用一次性预占消费和事后对账；参考片与 corpus 在使用时重验当前
权利、用途、索引和源文件身份；飞行记录只输出限量脱敏的本地观察数据。

本轮新增 Timebase V2、类型化 Timeline Projection、可校验 Command Journal、Editor
CLI/API 与本地 `/editor` 专业调整工作台。V2 工作台支持多选吸附、trim、split、
EDL 重排、Marker、工作区、多画幅安全框、波形、Project Bin、许可/来源校验替换，
以及会进入 FFmpeg 终渲染的 overlay `x/y` 键帧。用户可以在不建立第二套工程状态
的前提下查看轨道、执行 allowlist 内的结构/时序/几何修改、撤销/重做并获得必须
重跑的 QC 清单。
浏览器按 EDL 把成片播放头映射到源片，但转场 overlap 仍为单画面近似；正式成片
唯一由通过当前 runtime probe 的 FFmpeg Render Graph 生成。日志损坏可显式恢复
最后有效快照，合法外部修改可显式重开 session，两者都要求当前 SHA 并归档旧状态。

本轮还新增根目录受限的本地 stdio MCP：Codex 与 Claude Code 可以发现紧凑读取工具，
并通过同一 SHA/Journal 路径执行安全操作；未知参数、越界路径和整项目覆盖均被拒绝。
参考片流程可绑定本地节奏技术证据，但场景变化、能量、起音和 BPM 始终只是候选，
不声称语义理解。首跑演示在本机生成合成素材并完成可验证编辑，90 秒只作为离线
激活目标，不作为成片质量结论。

2026-08-30 全产品审计后，当前交付面进一步补齐：官方 stdin 安装器可从固定 HTTPS
地址取得并校验唯一 release-channel 合同；Studio 在进程启动时预热不可变生产目录，
后续请求只动态合并本地自定义风格；本地 HTTP 对非 object JSON 和超过 1 MB 的请求
返回稳定的 400/413；macOS smoke 使用隔离 Python venv。当前产品事实由静态门禁
推导并核对：完整回归 160 项、65 个模板、69 个设计条目、23 个公共核心资源和
132 个可分配效果。中英文官网各自拥有正确的文档语言根节点。

非目标：自动发布、无授权外传或付费、替代人工正常速度审片、承诺真实流量增长，
以及复制第三方项目源码或参考片的独特表达。Rust/WGPU 渲染仍只是明确标记为
`not_implemented` 的 provider 边界，当前不属于可用能力或正式成片能力。
OpenCut/OpenMontage 的广义 NLE 与提供者广度也不是当前追赶目标；咔嚓优先优化
安装到首个可验证候选的时间、恢复性、证据链和真人内容质量。

## 当前目标用户与场景

咔嚓面向使用 Codex 或 Claude Code 的专业视频创作者，首要生产对象是“行者大灰”
真人口播、工具演示、读书与 AI 内容。典型场景包括从脚本或源视频建立项目、
首剪、字幕与动态字景、声音、视觉包装、审片、增量返工和本地候选交付。

## 当前问题与价值主张

产品解决“AI 能生成效果，但缺少可恢复工程、证据链、版权/费用边界和完整验收”
的问题。核心价值不是一键自动成片，而是把人类内容判断与代码化生产门禁连接起来。

## 当前能力、范围与非目标

当前能力包括 V7 四里程碑编排、V8 质量不降级效率、Timeline IR、Render Graph、
统一审片、Agent 控制面、五套视觉语言、电影化字景，以及本轮新增的能力路由、
费用账本、参考片原创化、片段语料、制作飞行记录、Series/Hero 路由和四套工作流包。
其中付费执行采用一次性预占消费和事后对账；参考片与 corpus 在使用时重验当前
权利、用途、索引和源文件身份；飞行记录只输出限量脱敏的本地观察数据。

非目标：自动发布、无授权外传或付费、替代人工正常速度审片、承诺真实流量增长，
以及复制第三方项目源码或参考片的独特表达。

# Metrics and learning

> 对账修订：`openmontage-optimization-2026-08-26`。

## 产品目标与核心指标

工程目标是新增合同的专门回归全部通过、完整回归 154 项通过、Git diff 与隐私
检查通过、Codex/Claude 安装与源码一致。产品质量继续使用语义、连接、字幕、
视觉、声音和完整通看六项护栏；发布和增长指标另行观察。

## 市场、用户与运营反馈

本轮没有真实付费提供者、发布、部署或平台数据，因此不能形成市场或增长结论。
当前可验证反馈是用户明确要求把 OpenMontage 对比建议全面产品化并持续留痕。

## 已验证结论与待验证假设

已验证：确定性内核可以通过适配器扩展而无需改造成“无代码编排”；硬门禁可以
阻止不兼容、未授权外传和未知费用；一次性预算消费可阻断授权重放；参考片和
corpus 的源身份漂移可由文件合同检测；观察日志可在不暴露原始载荷的情况下回放。

待验证：外部提供者真实可靠性与费用、Hero 引擎在目标项目中的生产质量、四套
工作流在真实项目的完成时间与人审结果、对“行者大灰”内容效率和效果的长期影响。

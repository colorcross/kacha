# Metrics and learning

> 对账修订：`kacha-human-agent-editing-2026-08-31`。

## 当前工程基线

历史基线回归已从 159 项增长到本轮完整回归 170 项；必须保持完整回归、静态/隐私、
安装器、官网构建与浏览器旅程全部通过。当前目录事实为 65 个模板、69 个设计条目、
23 个公共核心资源和 132 个可分配效果。`scripts/verify_product_truth.mjs` 在静态门禁
中推导并核对这些值，历史快照不随当前值机械改写。

性能基线仅代表 2026-08-30 的审计主机：修复前 `/api/bootstrap` 三次为 8.524、
11.585 和 10.571 秒，静态首页约 1 毫秒。修复后重启服务并等待 ready，三次 bootstrap
为 0.0145、0.0083 和 0.0079 秒，均低于 1 秒；该结果只证明本次审计主机上的进程内
预热与缓存闭环，不得外推为所有硬件 SLO。

## 产品指标分层

| 层级 | 指标 | 成功定义 | 当前状态 |
| --- | --- | --- | --- |
| 工程 | gate pass | 当前提交的静态、回归、安装、网站和目标环境证据通过 | 有基线 |
| 激活 | install-to-first-project | 明确安装尝试中，在同一受控会话创建首个有效项目 | 未采集 |
| 首跑 | offline-first-edit | 合成素材中完成 SHA 编辑、undo/redo、校验与 FFmpeg 渲染 | 本机约 2.5 秒，非真实用户证据 |
| 价值 | first verified candidate | 项目得到可解码候选、自动 QC 和绑定哈希的人工审片 | 未采集 |
| 效率 | active editing time | 同源任务中排除机器等待后的人工主动操作时间 | 未采集 |
| 质量 | human approval | 正常速度通看六项护栏均无退化 | 未采集 |
| 留存 | four-week return | 首个验证候选后 28 天内再次完成有效项目 | 未采集 |
| 经营 | support and economics | 每活跃创作者支持时长、外部成本、收入与毛利 | 未采集 |

指标口径、最小数据和同源对照规则见
[采用与价值度量合同](adoption-measurement.md)。GitHub stars、clone 和 page view 只算
公开获取信号，不等于激活、留存或价值。

## 当前已验证与未知

已验证的是源代码、162 项回归、页面和本机行为；Linux CI 仍需本轮提交后的回读。
macOS smoke 修复、Pages 发布、远程 stdin 安装和双 Agent 安装必须在推送后分别回读。

尚未验证目标用户访谈、首次候选成功率、四周留存、创作者节省时间、真实输出质量、
收入和支持成本。没有这些证据时，不形成“提升效率”“增长”或“达到产品市场匹配”
的结论。浏览器交互通过也不等于成片质量提升，后者仍需真实项目、正式渲染和正常
速度人工审片。

# Product truth map

这里记录当前真实产品，而不是仅保存产品启动时的设想。每轮迭代先更新 `quality/product-documentation-state.json` 的变化影响，再同步以下文档：

- `current-product.md`：当前用户、问题、价值、范围、能力和非目标。
- `product-experience.md`：信息架构、关键旅程、页面/端与交互。
- `business-rules.md`：业务规则、权限、状态机和边界。
- `metrics-and-learning.md`：目标、指标、市场反馈和最新认知。
- `adoption-measurement.md`：本地优先的采用、价值、质量、留存和经营度量合同。
- `roadmap-and-decisions.md`：当前路线、重要决定和被替代定义。

迁移不会覆盖原文档。首次接入时应全面了解当前产品，把仍有效内容重写到这里，并把过期定义登记为被替代历史。

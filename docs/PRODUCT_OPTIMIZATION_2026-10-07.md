# 咔嚓产品优化与验收 · 2026-10-07

## 方向与范围

咔嚓继续服务本地、可追溯的视频制作：从内容或已有视频建项，经过 Timeline 调整、审片、交付。Timeline IR 是生产真值，Canvas 是近似预览，正式成片由 FFmpeg 生成。本轮优先降低中断、重复操作和目标混淆造成的返工，沿用现有视觉语言，不新增收费服务或扩大自动执行权限。

起点为 `b64e2bc`。九份已有节目规则文档保持原样；基线保存在 `output/optimization-2026-10-07/`。本轮不迁移历史节目、不提交私有音效、不用测试素材替代真人节目的质量验收。

## 诊断、实施与验收

| 维度 | 发现与实施 | 验收方式 |
| --- | --- | --- |
| 产品主线 | 内容建项只冻结输入，创建结果需绑定当前表单；用简明文案解释下一步 | 脚本/选题切换、创建成功/受阻/失败、输入变更均有明确状态 |
| 性能与瓶颈 | 视频探测、预检、编译、内容建项在 HTTP 主线程同步执行；纳入共享的有界 Worker 执行器 | 忙时仍可响应事件循环；统一并发上限；路径别名与同目录任务不能重复执行 |
| 资源与成本 | GET/Range 中止后源流不关闭，已用真实 HTTP 复现文件句柄泄漏；统一正常、断开和错误的流生命周期 | 大文件普通/Range 请求中断后流关闭；源错误不杀死服务；HEAD/非法 Range 正常 |
| 代码健壮性 | 打开 B 期间编辑 A，响应倒序会留下全局 busy；打开/修改/复制/交付互斥并绑定目标 | 受控延迟与重复提交反例；失败后可恢复，旧工程不能继续写入 |
| UI 简洁性 | 建项文案冗长、仅按钮忙态、过期结果仍显示；收敛成输入→建立→进入项目 | 整表单冻结；持续反馈；结果失效；保留失败输入；手机宽度无溢出 |
| 交互一致性 | 内容栏目与视觉风格可选出无效组合；编辑交付缺少统一提交保护 | 仅可选匹配风格；五个页面统一内容/配置/项目/调整/审片导航与当前页提示；键盘与鼠标遵守相同忙态；重复复制/导出只发一次 |
| 工程与交付 | 增加资源和竞态回归，独立复审后按同一 SHA 推送与部署 | 本地检查、CI、Pages、Codex/Claude 安装、已安装运行回读分别记录 |

## 实施原则和边界

- 有界执行器不维护无限排队；繁忙返回 409，明确本次未重复提交。按规范化真实路径互斥，Worker 正常退出或异常退出才释放容量。
- 不强制终止有写入副作用的任务，避免把“取消等待”误当作“撤销落盘”。
- 保留强媒体身份核验。实测 128 MiB 媒体冷核验读 128 MiB，热核验读 0 字节；已有哈希缓存，不能声称所有轮询都重复哈希。Worker 隔离改善主线程响应性，不据此声称减少哈希 I/O 或生产费用。
- 真实预览跨冻结运行时的同步验证仍是后续性能对象；要以复用 Worker/核验缓存解决，不能用单纯 stat 替代正式身份核验。
- 本轮不新增付费生成。实际生产端到端耗时、返工率、费用下降幅度，需要真实节目样本，保持未知。

## 独立 review 与追加修复

独立 reviewer 在初版实现中发现两项 P2，均已关闭并复验：

1. Worker 把媒体真实路径用于执行，改变软链接素材的配置和默认输出目录。修复为真实路径只做互斥，执行保留选择路径；真实 MP4 对照结果一致，limit=2 验证别名互斥与共享输出锁。
2. 切换工程时，尚在 debounce 阶段的旧预览仍可能提交。切换和版本变化均取消定时器，发请求前检查 generation 与操作状态；受控时钟验证旧请求数为 0，在途旧回复不会展示。

发布前 `npm audit` 检出 sharp <0.35.5 的高危公告（[维护者说明](https://github.com/advisories/GHSA-wq5f-xc86-pv6w)）。将 Next 与 Miniflare 的 sharp 统一固定到 0.35.5，生产/全依赖审计恢复为 0，无新增豁免。

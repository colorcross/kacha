# 咔嚓产品优化与复核 · 2026-10-15

基线 `b2e1a8b`。本轮覆盖通用与大灰AI的素材配置、内容入口、项目状态、调整、审片、后台任务、媒体渲染及交付链；不修改真实节目、私有素材或既有冻结运行时。完整实施范围是以下已确认问题；未发现问题的能力保留已有合同并运行相关回归。

## 产品方向与方案

咔嚓继续以自然语言 Agent 驱动制作，工作台承担配置、观察、可撤销调整和审片。四步用户主线是理解素材、形成初稿、针对问题修改、验证交付；不增加一套独立时间线或强制包装步骤。通用工具默认自然表达，大灰AI栏目显式选择，历史作品保持原身份。新增专业工具和 wise-motion 都回到同一候选与证据链。

本轮按可复现缺陷实施：先让用户看到的选择等于实际合同，再处理失败恢复、重复读取成本，最后回归渲染和发布。既有石墨黑/橙色控制层、字体和导航保持；不引入额外 UI 库、生成服务或付费调用。

## Review范围与边界

- 产品/交互：内容、配置、项目、调整、审片五入口；通用和大灰AI切换、项目身份、过时响应、失败重读、撤销重做。
- 性能/成本：不重复提交昂贵任务，不削弱SHA验证，减少重复读盘及轮询。仅声明局部读盘/请求改善，不将合成样本推成整体制作提速。wise-motion每包保留中间文件以支持复现，本轮不自动删除缓存或更换模型。
- 健壮性/安全：源只读、输出排他锁、资源并发上限、取消与恢复、HTTP同源限制、输入和运行时身份、许可及私有资源边界。
- 剪辑能力：既有粗精剪、网络素材、图文/视频叠加、转场、动效、音频、BGM/SFX、专业工具通过对应专项及全量门禁复核；没有新付费生成或修改真实节目。
- 质量：Timeline IR/FFmpeg仍为正式时间线与渲染依据，Canvas仅近似预览。技术媒体回归、UI走查、人工完整节目审片分别记录。
- 交付：精确提交与远端CI、双Agent原子安装、运行服务重启和安装入口实测分别留证。网站未变则不重建网站；本轮部署目标是本机工作台和插件。
